# Практична робота №4

## Адаптивна верстка: CSS Grid/Flexbox, медіа-запити

### Тема
Адаптивна верстка: CSS Grid/Flexbox, медіа-запити

### Формат
Комп'ютерний практикум

### Мета роботи
Перевести верстку сторінки з практикуму 3 на сучасні механізми розташування елементів -
Flexbox і CSS Grid - і додати медіа-запити для трьох типових breakpoint'ів (мобільний, планшет,
десктоп), щоб сторінка коректно й зручно виглядала на екранах різної ширини.

### Варіант завдання
**Варіант 7 — Список бажань (Wishlist)**

- **Назва проєкту:** `wishlist-app`
- **Title сторінки:** «Список бажань»
- **Мобільний:** картки бажань - 1 колонка, aside «Сума» під main.
- **Планшет:** картки бажань - 2 колонки.
- **Десктоп:** картки бажань - 3 колонки; aside «Сума» закріплений поруч через `grid-template-columns: 3fr 1fr`.

### Необхідні знання й інструменти

- **Знання:** CSS-селектори й box model з практикуму 3; наявний зовнішній файл `css/style.css` із
базовою стилізацією header, main, карток, aside, footer.
- **Інструменти:** редактор коду, Live Server, Git; DevTools з режимом емуляції пристроїв
(responsive design mode / device toolbar) для перевірки вигляду сторінки на різній ширині вікна.

### Хід роботи

**Крок 1. Перевірка viewport**
У секції `<head>` файлу `index.html` наявний тег `<meta name="viewport" content="width=device-width, initial-scale=1.0">`, завдяки якому мобільні браузери не масштабують сторінку як десктопну.

**Крок 2. Переведення навігації на Flexbox**
Шапці сайту додано клас `.site-header` і зроблено її flex-контейнером (`display: flex`, `flex-wrap: wrap`, `gap: 12px`). Навігація `nav` також є flex-контейнером; відступи між посиланнями задаються через `gap` замість `margin-right`.

**Крок 3. Переведення галереї карток на Grid**
Контейнеру з картками бажань (`#wish-items`) додано клас `.cards` з `display: grid` і базовою (мобільною) кількістю колонок - `grid-template-columns: 1fr`. Для розташування `main` і `aside` поруч їх обгорнуто спільним контейнером `.layout`, який також є grid-контейнером.

**Крок 4. Мобільні (базові) стилі**
Стилі написано за підходом mobile-first: поза медіа-запитами все розташовано в один стовпчик - заголовок і навігація в шапці вишикувані вертикально (`flex-direction: column`), картки - в 1 колонку, блок `aside` «Сума» - під `main`. Зменшено розмір заголовка та відступи.

**Крок 5. Медіа-запит для планшета**
У `@media (min-width: 600px)` сітку карток збільшено до 2 колонок (`repeat(2, 1fr)`), навігацію переведено в горизонтальний ряд (`flex-direction: row`), збільшено відступи й розмір заголовка; блок «Сума» обмежено шириною 400px і відцентровано.

**Крок 6. Медіа-запит для десктопа**
У `@media (min-width: 1024px)` шапку перебудовано в рядок (заголовок зліва, навігація справа, `justify-content: space-between`), сітку карток збільшено до 3 колонок, `main` і `aside` розташовано поруч через `grid-template-columns: 3fr 1fr`. Максимальну ширину контенту збільшено до 1280px, збільшено відступи. Блок «Сума» закріплено поруч за допомогою `position: sticky`, тож він лишається видимим під час прокрутки.

**Крок 7. Обмеження ширини зображень**
Додано правило `img { max-width: 100%; height: auto; }`, щоб зображення не переповнювали вузькі контейнери на мобільному екрані.

**Крок 8. Перевірка breakpoint'ів**
У режимі емуляції пристроїв DevTools перевірено вигляд сторінки на ширині 375px (мобільний), 768px (планшет) і 1280px (десктоп). Горизонтальна прокрутка відсутня, елементи не накладаються.

**Крок 9. Збереження змін**
Переконано, що для основного макета не використовуються `float` чи `position: absolute` - лише Flexbox і Grid. Зміни зафіксовано в Git комітом з описовим повідомленням.
```
git add .
git commit -m "Практична робота №4: адаптивна верстка на Flexbox/Grid, медіа-запити 600px/1024px"
```

### Опис виконаної роботи

1. Перевірено наявність тегу viewport у `head` документа.
2. Шапку сайту (`.site-header`) і навігацію переведено на Flexbox; відступи між елементами задано через `gap`.
3. Галерею карток бажань (`.cards`) переведено на CSS Grid, а `main` і `aside` обгорнуто grid-контейнером `.layout`.
4. Написано мобільні базові стилі: один стовпчик, вертикальна навігація, 1 колонка карток, «Сума» під основним вмістом.
5. Додано медіа-запит для планшета (`min-width: 600px`): 2 колонки карток, горизонтальна навігація.
6. Додано медіа-запит для десктопа (`min-width: 1024px`): 3 колонки карток, `main` і `aside` поруч (`3fr 1fr`), закріплений блок «Сума», більша ширина контенту й відступи.
7. Обмежено ширину зображень правилом `img { max-width: 100%; height: auto; }`.
8. Перевірено вигляд сторінки на трьох breakpoint'ах у DevTools - горизонтальної прокрутки та накладання елементів немає.
9. Макет побудовано лише на Flexbox і Grid, без `float` і `position: absolute`; зміни збережено в Git.

### Висновок
У результаті виконання практичної роботи верстку сторінки «Список бажань» переведено на сучасні механізми розташування елементів. Flexbox застосовано для одновимірних елементів - шапки та навігації, а CSS Grid - для двовимірних структур: галереї карток і макета сторінки з основним вмістом та бічною панеллю. За підходом mobile-first базові стилі описують найпростіший мобільний вигляд, а медіа-запити для планшета (600px) і десктопа (1024px) прогресивно ускладнюють макет. Сторінка коректно відображається на екранах різної ширини без горизонтальної прокрутки.
